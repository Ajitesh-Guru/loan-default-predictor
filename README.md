# Loan Default Prediction

PyTorch feed-forward neural network for binary loan-default
classification on a 255K-row retail lending dataset.

- Two hidden layers (64, 32 units), ReLU, sigmoid output
- Binary cross-entropy loss, Adam optimizer, 500 epochs
- 10 input features after preprocessing

Dataset not included. Download Loan_default.csv separately
and place it in the project root before running.
